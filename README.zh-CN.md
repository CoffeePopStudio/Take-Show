# TakeShow

[English](README.md)

TakeShow 是一个轻量、偏原版向的扩展模组：专注于将 Minecraft 中玩法延伸较少、存在感偏弱的内容，补全为更实用、更有互动的玩法，而不是引入庞大复杂的新系统，或用大量内容堆满世界。

本项目目前仍处于 **开发中 / 未完成** 状态，后续可能会继续扩展并进行平衡调整。

## 功能

| 功能 | 说明 |
| --- | --- |
| **回响护符（Echo Charm）** | 右键触发一次“回声 Ping”，使附近生物短暂发光，并提供粒子/音效反馈与冷却。 |
| **回响紊乱（Echo Distortion）** | 与回声能力绑定的代价效果：移动速度降低。 |
| **鸣响镐（Resonant Pickaxe）** | 挖掘石质方块时，扫描一定范围内未暴露在空气中的隐藏矿石，并短暂高亮显示。 |
| **附魔：瞅什么瞅？！（Look What?!）** | 最高 III 级的防御/反制向附魔，被攻击时对攻击者施加减益；高等级在举盾时提供更强反制能力。 |
| **联机友好** | 由服务端筛选目标与坐标并下发，客户端负责短时高亮渲染。 |
| **进度（Advancements）** | 提供少量进度，用于引导首次使用。 |

## 依赖

- Fabric API
